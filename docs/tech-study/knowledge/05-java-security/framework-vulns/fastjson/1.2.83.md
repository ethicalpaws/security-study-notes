# Fastjson1.2.83

## 核心原理
>FastJSON 在处理 Throwable（异常）类时，允许用户通过 @type 指定任意异常子类，并调用其带 String 参数的构造方法或 setter。攻击者利用继承了 Throwable 且存在危险构造方法/setter 的类（gadget），在特定 API 调用条件下实现 RCE。

## 源码审计

>禁用AutoType机制

```java
} else if (Throwable.class.isAssignableFrom(clazz)) {
    deserializer = new ThrowableDeserializer(this, clazz);
}
```

任何继承 Throwable 的类（包括 Exception、RuntimeException 及其所有子类），都会走 ThrowableDeserializer，而不是普通的 JavaBeanDeserializer。

在处理 JSON 时：

- 如果发现 @type 字段，调用 parser.getConfig().checkAutoType(exClassName, Throwable.class, ...)

- 由于传入了 expectClass = Throwable.class，checkAutoType 对 Throwable 的子类放宽了限制

- 随后调用 createException() 方法实例化异常对象

## 利用条件

- 必须使用 JSON.parse 或 JSON.parseObject	且未指定具体的反序列化类

- 不能指定目标类	如 JSON.parseObject(json, User.class) 是不受影响的

- 需要合适的 Gadget 类	必须是 Throwable 子类，且存在可利用的构造方法/setter

- 需要特定环境的依赖	不同的 Classpath 决定了哪些 gadget 可用

>攻击复杂度较高：虽然漏洞评分 CVSS 8.1（高危），但实际利用需要“在特定条件下”且“攻击者需要研究目标环境找到合适的 gadget 类”
