   🔍 Cairn 框架深度解析

  一、核心架构

  ┌─────────────────────────────────────────────────────────────┐
  │                      Cairn Server (8000)                     │
  │            维护 Project / Fact / Intent / Hint             │
  └────────────────────────────┬────────────────────────────────┘
                               │ HTTP API
  ┌────────────────────────────▼────────────────────────────────┐
  │                    Dispatcher (调度器)                       │
  │  - 调度任务类型 (bootstrap/reason/explore)                  │
  │  - 管理 Worker 生命周期                                      │
  │  - 处理超时、重试、conclude                                  │
  └────────────────────────────┬────────────────────────────────┘
                               │ 本地进程 (local) 或 容器 (container)
  ┌────────────────────────────▼────────────────────────────────┐
  │                    Worker / Agent CLI                        │
  │              Codex CLI / Claude Code CLI                     │
  │         执行 Agent 任务，输出结构化 JSON                      │
  └─────────────────────────────────────────────────────────────┘

  二、三种任务类型

  ┌───────────┬────────────────────┬────────────────────────────┬──────────────────┐
  │   任务    │        时机        │            输入            │       输出       │
  ├───────────┼────────────────────┼────────────────────────────┼──────────────────┤
  │ bootstrap │ 项目创建时，一次性 │ origin, goal, hints        │ fact + complete  │
  ├───────────┼────────────────────┼────────────────────────────┼──────────────────┤
  │ reason    │ 读图判断方向       │ graph_yaml, fact_ids,      │ complete /       │
  │           │                    │ open_intents               │ intent / 空      │
  ├───────────┼────────────────────┼────────────────────────────┼──────────────────┤
  │ explore   │ 执行具体探索       │ graph_yaml, intent_id,     │ fact 描述        │
  │           │                    │ description                │                  │
  └───────────┴────────────────────┴────────────────────────────┴──────────────────┘

  三、任务执行流程

  项目创建
      │
      ▼
  bootstrap (直接尝试解决问题)
      │
      ├── 成功 → fact + complete → 项目完成
      │
      └── 失败/超时 → conclude (总结当前进展) → fact
                                │
                                ▼
                          reason (判断是否完成，或提出新 intent)
                                │
                                ├── 完成 → complete
                                │
                                ├── 新 intent → explore
                                │
                                └── 无 intent → 等待

  四、Prompt 模板

  位于 cairn/src/cairn/dispatcher/prompts/default/:
  - bootstrap.md - 直接解决问题
  - bootstrap_conclude.md - 收尾总结
  - reason.md - 判断方向
  - explore.md - 执行探索
  - explore_conclude.md - 探索收尾

  七、改进方案

  7.1 自定义 Prompt（去字典化）

  修改 prompts/default/explore.md，加入约束：

  # 规则
  - **禁止**使用预设字典（如 rockyou.txt）进行暴力破解
  - **禁止**无差别的端口扫描（如 masscan）
  - 只允许定向探索，根据已有 Fact 动态生成探测策略
  - 优先使用信息收集而非暴力破解

  7.2 多模型互审配置

  workers:
    - name: "minimax-m3-doer"
      type: "codex"
      task_types: [bootstrap, explore]
      max_running: 2
      priority: 0
      env:
        CODEX_MODEL: "m3"
        CODEX_BASE_URL: "https://api.minimax.chat/v1"
        OPENAI_API_KEY: "sk-cp-xxx"

    - name: "claude-reviewer"
      type: "claudecode"
      task_types: [reason]  # 只做审查
      max_running: 1
      priority: 1
      env:
        ANTHROPIC_MODEL: "claude-sonnet-4-20250514"
        ANTHROPIC_BASE_URL: "https://api.deepseek.com/anthropic"
        ANTHROPIC_AUTH_TOKEN: "sk-ant-xxx"
